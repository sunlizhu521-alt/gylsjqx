备货需求分配明细字段来源

备货需求表按物料编码合并为一行，数量相加，OA备货流程号去重后用“/”连接；其他不同字段值用“、”保留。维度和采购分工信息按物料编码匹配，事业部按申请人匹配。筛选与导出均使用合并后的明细。

明细字段 来源文件 原始字段 / 位置 取值与匹配规则
采购单订单下单人Dim-采购部分工明细采购单订单下单人优先按“采购组＋物料编码”匹配；无结果时按物料编码匹配，多个结果用“、”合并。
事业部Dim-花名册（姓名&一级部门）姓名、一级部门（A、B列）使用备货需求表的申请人匹配花名册姓名，返回一级部门。
申请人备货需求表创建人 / 申请人 / OA申请人 / 流程申请人直接读取匹配到的申请人字段。
供应商简称Dim-采购部分工明细供应商简称按物料编码匹配，多个供应商用“、”合并。
物料编码备货需求表识别码 / 物料编码等作为明细主匹配键，用于关联商品分类表和采购分工明细。
SKUDim-YL医疗器械商品分类SKU（C列）按物料编码匹配商品分类表后取得。
物料名称Dim-YL医疗器械商品分类金蝶名称 / 物料名称（D列）按物料编码匹配商品分类表后取得。
数量备货需求表数量读取“数量”列；存在同名列时，读取紧邻“要求货好时间”前的明细数量。缺失、无法定位或非数字时留空并提示待核对，不从其他字段取数。同一物料数量相加，任一来源数量缺失或无效时，合计留空并提示待核对。
OA备货流程号备货需求表流程号 / OA备货流程号等同一物料编码的流程号去重后按来源顺序用“/”连接。
采购主体备货需求表采购主体 / 采购公司 / 采购组织等直接读取采购主体类字段。
采购分工明细是否存在系统计算物料编码物料编码存在于 Dim-采购部分工明细时显示“是”，否则显示“否”。
供应商反馈交期人工填写—默认留空，供导出后填写供应商反馈交期。
采购单订单号人工填写—默认留空，供导出后填写采购单订单号。
要求货好时间备货需求表要求货好时间 / 要求货好日期等直接读取要求货好时间类字段。
起订量Dim-采购部分工明细“产品线明细”工作表 J列仅从名称包含“产品线明细”的工作表读取，按物料编码匹配。
起订量是否满足系统计算数量、起订量同一物料合计数量大于或等于起订量时显示“满足”，否则显示“不满足”；缺少任一数值时留空。
备货原因备货需求表备货原因 / 申请原因 / 需求原因等直接读取原因类字段。
